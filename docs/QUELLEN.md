# Quellen der Medien

## Klänge

- **Reifenquietschen** (`assets/sounds/reifen_quietschen.ogg`): „Tires Squealing“ von Mike Koenig, https://soundbible.com/1178-Tires-Squealing.html, Lizenz [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Geändert: gleichmäßiger Ausschnitt (0,06–0,62 s) als Mono, vorwärts, rückwärts und 5 % höher zu einer nahtlosen Schleife von 1,4 s verbunden, Lautheit angeglichen, als OGG Vorbis gespeichert (19.10.2026). Die Namensnennung steht auch im Hauptmenü.
- Alle übrigen Klänge und die Musik entstehen im Code (`SoundSynth`, `SoundBank`, `MusicSynth`).
