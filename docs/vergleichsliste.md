# Vergleichsliste Zellenphase ↔ Spore

Je Bereich: Referenz (Spore-Handbuch, Abschnitte „Cell Stage“ und „Cell Creator“), umgesetztes Verhalten, bekannter Unterschied, Nutzertest. Wird im Lauf des Projekts gefüllt.

| Bereich | Referenz | Umgesetzt | Unterschied | Nutzertest |
|---|---|---|---|---|
| Steuerung | Schwimmen mit gedrückter Maustaste in Richtung Zeiger, alternativ WASD | | | |
| Kamera/Größe | Kamera folgt, zoomt mit jeder Größenstufe heraus | | | |
| Nahrung/Kampf | Maul bestimmt Nahrung (Filter, Kiefer, Rüssel); Treffer nur mit dem Maul bzw. mit Abwehrteilen | | | |
| Editor | Partner rufen, Editor mit DNA-Kosten, Teile platzieren, drehen, Symmetrie | | | |
| Optik | Räumlich wirkende Zellen, Tiefenebenen, Partikel | | | |
| Ablauf | Nahrung → DNA → Wachstum → Teilefunde → Editor → Ende der Zellenphase | | | |
